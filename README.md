# Brazilian E-Commerce Data Analysis Dashboard

##Deskripsi
Analisis data e-commerce publik dari Brazil untuk menjawab beberapa pertanyaan bisnis:
- Negara bagian dengan pelanggan dan penjual terbanyak.
- Distribusi status pesanan.
- Pola transaksi harian.

## Struktur Folder
- **data/**: Berisi file CSV asli (data1.csv, data2.csv, data3.csv, data4.csv)
- **dashboard/**: Berisi file utama dashboard (app.py) dan file data gabungan (main_data.csv)
- **notebook.ipynb**: Notebook analisis data yang telah dijalankan
- **requirements.txt**: Daftar dependensi yang digunakan
- **url.txt**: URL deploy dashboard atau informasi dataset
